Token Radar ranks pre-token protocols from a sealed snapshot and presents their estimated values alongside a practical farm plan. Its peer-multiple model uses live-token market-cap-to-TVL comparables, adjusted for category, growth, age and chain breadth.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
